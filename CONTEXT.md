# Fabian Website

This context defines how the public one-page website is named and addressed.

## Language

**Website**:
The public one-page site representing Fabian.
_Avoid_: Server, application

**Canonical domain**:
`fabian.sg`, the authoritative public address of the Website.
_Avoid_: `www.fabian.sg`, GitHub Pages URL

**Domain alias**:
`www.fabian.sg`, an alternate address that redirects to the Canonical domain.
_Avoid_: Canonical domain
